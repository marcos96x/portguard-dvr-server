Exemplo de exibição no webapp

O navegador não toca RTSP. Use as URLs devolvidas pela API (cameras[].urls). O jeito mais simples é um iframe apontando para urls.iframe.

iframe (mais simples)

No seu app, depois de cadastrar o DVR com POST /api/dvrs, basta fazer:

<iframe src="CAMERAS[0].urls.iframe" allow="autoplay; fullscreen"></iframe>
